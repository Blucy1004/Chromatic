# 실력 검증과 한계

## 독립적으로 해답을 검증한 전술 진단

메이트 1/2/3수는 Python 규칙 구현의 bounded AND/OR 탐색으로 최소 깊이와 모든 정답 수를 확인했습니다. 강제 잡기는 유일 합법 수이면서 잡기인지 확인했고, 승격·스테일메이트 회피는 즉시 메이트 해답을 검증했습니다. Perpetual 사례는 실제 합법 체크 반복 뒤 3회 반복 종료를 검사합니다. 종합적인 수비·영구 체크 선택 능력을 증명하는 세트는 아닙니다.

같은 가중치, 한 수 25ms, 8개 진단 사례에서:

| 경로 | 정답 |
|---|---:|
| v0.1 기준 | 5/8 |
| CHROMATIC 기본 | 6/8 |
| CHROMATIC 깊은 메이트 증명 옵션 | 8/8 |
| FPU reduction .25 진단 | 6/8 |

기준 모델은 즉시 메이트를 놓쳤습니다. 기본의 작은 terminal proof가 이를 해결했습니다. 깊은 옵션은 더 많은 검색 비용을 쓰며, 이 작은 진단 세트를 개발 중 사용했으므로 독립 홀드아웃 점수라고 주장하지 않습니다. FPU의 이 진단만으로 기본값을 바꾸거나 Elo 개선을 주장하지 않았습니다.

## 고정 시간 색 교환 대결

동일 CPU affinity=1, 한 수 10ms, 고정 오프닝, 색 교환을 사용했습니다. 엔진 비교는 같은 원본 가중치로 C++/검색 변경을 비교하고, 모델 비교는 동일 CHROMATIC 엔진에서 Small과 Tiny를 비교했습니다. 최대 256플라이, 세대 대결은 최대 512플라이입니다.

| 실험 | 후보 승 | 무 | 패 | 미완료 | 판정 |
|---|---:|---:|---:|---:|---|
| engine-match | 1 | 5 | 0 | 2 | insufficient_evidence |
| model-match | 0 | 2 | 0 | 2 | insufficient_evidence |
| generation-match | 0 | 3 | 0 | 1 | insufficient_evidence |

미완료를 무승부나 패배로 바꾸지 않았습니다. 미완료가 있는 대결의 Elo/신뢰구간은 비워 두고, 완료 대결도 작은 오프닝 표본에서 승격 신뢰하한이 충족됐는지 따로 검사했습니다. 고정 오프닝을 반복해 독립 증거 수를 부풀리지 않도록 같은 오프닝은 하나의 cluster로 취급합니다. PGN과 한 수별 시간·방문 수는 `reports/final/*match.*`에 있습니다.

**이번 결과로 통계적으로 확정된 Elo 향상을 주장하지 않습니다.** 작은 실험에서 패배가 없거나 더 많이 이긴 사실도 강도 확정으로 확대하지 않습니다. 무영과의 대결은 수행하지 않았습니다.

## 교사 없는 자가학습 한 세대

기존 128개 bootstrap 자료를 재사용했고 이후 교사를 다시 호출하지 않았습니다. 새 실행은 4판, 64 MCTS 예산/수, 최대 512플라이, 6플라이 오프닝 다양화를 사용했습니다. 4/4판 완료, 0판 미완료, 173개 위치를 얻었고 완료 대국 중 무승부율은 50%였습니다. 새 결과에 인공 승패/무승부 패널티를 넣지 않았습니다.

후보는 이 자가대국 데이터로만 100스텝 학습했습니다. 정책/WDL/validation/gradient/entropy/Brier/ECE/throughput은 `runs/overdrive/generation_0000/candidate.train.json`에 있습니다. 독립 그룹이 부족한 경우 validation은 없다고 명시합니다. 같은 완료 세대의 재시작이 상태를 바꾸지 않는 것도 확인했습니다.

후보 승격: **False**. 배포 챔피언은 **initial.pt**입니다. 실제로 승격한 이력이 없는 이번 실행에서 rollback을 했다고 주장하지 않으며, 해시 검증/이전 모델 복구는 별도 fixture로 검사했습니다.

## 반복 무승부 감사

원래 190개 selfplay 타깃은 전부 draw였습니다. 그 위치들의 평균 예측 draw 확률은 bootstrap 모델 약 6.8%에서 draw-only 학습 후보 약 99.94%로 바뀌었습니다. 이는 그 데이터의 보상 신호와 맞으며 낮은 학습 loss가 일반 실력을 보장하지 않는 사례입니다. 반복 판정과 가치 부호는 별도 테스트를 통과했습니다.

새 4판의 결과 다양화는 관찰했지만 탐색, 속도, 즉시 메이트 보호와 오프닝을 동시에 변경했으므로 특정 요인의 인과 효과나 무승부 편향의 해결을 입증하지 못합니다. 더 많은 완료 대국과 통제된 ablation이 필요합니다. 원시 근거는 `reports/final/draw-audit.json`입니다.
