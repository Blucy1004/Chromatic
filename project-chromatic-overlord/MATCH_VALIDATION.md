## 조건

Linux 스크리닝에서 선택한 직렬 구성을 각 모델의 기본 MCTS와 비교했다.
초기 모델의 전체 직렬15도 별도 비교했다. 모델/실행 파일 동일, 스레드1,
100ms/move, 동일 호스트 CPU 집합, 고정8오프닝을 색상 교대했다.
게임당 최대200개 신규 ply이며 종료되지 않으면 `*`로 남겼다.
점수·평가에 의한 임의 무승부나 패배 판정은 없다. 같은 규칙으로 청구 가능한

## 판정

**실제 Elo 개선은 미확정이다.** 사전 기준64개 독립 오프닝 페어에 미달한다. 8개 고정 오프닝의 재표집 구간은 모집단 대국 분포를 보장하지 않으며, 전승 시 무한 Elo 표시는 추정 경계이지 무한한 기력 개선이 아니다. 미완료 게임은 무승부로 합산하지 않고 완료된 양색 페어를 기준으로 계산했다. 모델을 바꾸는 대국은 하지 않았으므로 모델 효과에 대한 대국 Elo 결론도 없다. 전술 최상 구성과 실전 최상 구성이 같다고 확정하지 않았다.
